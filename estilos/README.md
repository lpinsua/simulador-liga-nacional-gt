# Estilos guardados del simulador (Apertura 2026)

Versiones anteriores del look and feel, guardadas para poder reutilizarlas. Todas usan los mismos datos (tabla tras la J20) y el mismo motor de simulación. Cada carpeta tiene un `index.html` independiente: para usar un estilo como versión principal, copiá su `index.html` a la raíz del repositorio y actualizá los datos (`TEAMS` y `FX`).

| Carpeta | Estilo | Descripción |
|---|---|---|
| `bloomberg/` | Terminal Bloomberg (actual) | Fondo negro, texto ámbar monoespaciado, equipos como tickers (`MUN GT Equity`), línea de comandos, cinta de cotizaciones. Flujo en 3 pasos: Equipo → Tabla → Simular. |
| `win95/` | Windows 95 | Ventanas `.EXE` con bordes en relieve, barra de tareas con menú Start, emojis por equipo, diálogo con confeti al clasificar. |
| `claro/` | Claro y divertido | Fondo claro, mucho espacio, título dinámico "¿Clasifica <equipo>?" con emoji, botones con emoji del equipo, confeti. |
| `limpio/` | Simulador Liga Nacional con emojis | Encabezado oscuro con franja fina de tejido, fichas con emoji por equipo, medidores circulares. |
| `chapina/` | Calculadora Chapina | Primera identidad propia: franja de tejido guatemalteco, paleta celeste/quetzal, abreviaturas de equipo. |
| `original/` | Primera versión Apertura 2026 | Diseño heredado del Clausura (claro, tabla y pestañas), ya con fase final y semis directas. |

La versión del Clausura 2026 está en `../clausura-2026/`.
